# Contribuer au projet Station-Coeur

Merci de votre interet pour contribuer au projet Station-Coeur !

## Comment contribuer

### Signaler un bug

1. Verifier que le bug n'a pas deja ete signale dans les [Issues](../../issues)
2. Ouvrir une nouvelle issue avec :
   - Description claire du probleme
   - Etapes pour reproduire
   - Comportement attendu vs observe
   - Screenshots si applicable

### Proposer une amelioration

1. Ouvrir une issue pour discuter de l'idee
2. Attendre validation avant de commencer le developpement

### Soumettre du code

1. Forker le repository
2. Creer une branche : `git checkout -b feature/ma-feature`
3. Faire vos modifications
4. Tester localement : `npm run dev`
5. Commiter : `git commit -m "feat: description"`
6. Pousser : `git push origin feature/ma-feature`
7. Ouvrir une Pull Request

### Conventions

- **Commits** : format conventionnel (`feat:`, `fix:`, `docs:`, etc.)
- **Code** : suivre le style existant (Prettier, ESLint)
- **Branches** : `feature/`, `fix/`, `docs/`

## Developpement local

```bash
npm install
npm run dev
```
